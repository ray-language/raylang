# Fuentes embebidas del playground

Las fuentes de marca de raylang, embebidas para que el playground se vea igual en cualquier navegador
(sin CDN externo, autocontenido). Ambas están bajo la **SIL Open Font License 1.1**
(<https://scripts.sil.org/OFL>), que permite su uso, incrustación y redistribución.

| Archivo | Fuente | Uso | Origen |
|---------|--------|-----|--------|
| `space-grotesk.woff2` | **Space Grotesk** (variable, 300–700) — © Florian Karsten | UI y títulos | <https://github.com/floriankarsten/space-grotesk> |
| `jetbrains-mono.woff2` | **JetBrains Mono** (Regular) — © 2020 JetBrains s.r.o. | Editor de código | <https://github.com/JetBrains/JetBrainsMono> |

El logotipo (wordmark/lockups en `assets/`) está **outlineado** (texto convertido a curvas) en Space
Grotesk, así que no depende de esta fuente para renderizarse.
